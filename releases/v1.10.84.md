# IICP PHP Directory v1.10.84

This release makes the evidence behind derived discovery fields explicit.

## Changes

- Added structured health reasons across reachability, backend, trust and policy
  dimensions.
- Separated Gold task-threshold progress from the remaining Gold requirements.
- Added the evidence basis for latency values and separated SDK compatibility
  from release currency.
- Added aggregate verified-operator diversity without exposing operator
  identifiers or claiming independent failure domains.
- Added a shared, content-free PHP/Rust discovery-evidence fixture.

The release is additive. It does not change ranking, eligibility, route exposure,
database schema or task-data-plane behavior. Publishing it does not authorize a
Genesis deployment or a Rust cutover.

# IICP PHP Directory v1.10.78.1

This release establishes the first immutable hardened-operator baseline from
the authoritative public repository. It packages source only and contains no
production configuration, credentials, database contents or website source.

## Upgrade notes

1. Verify the archive checksum, manifest and GitHub attestation.
2. Back up and restore the operator database into disposable infrastructure.
3. Build the separate hardened application and nginx images from the verified
   archive and compare their content manifests.
4. Run the one-shot migration profile before starting application services.
5. Rehearse readiness failure/recovery and backup/restore before any separately
   authorized operator adoption.

This release does not authorize deployment to the Genesis Seed. A genuine
previous-to-next hardened-image rollback rehearsal remains required when the
next hardened release is prepared.

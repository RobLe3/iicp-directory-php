# IICP PHP Directory v1.10.80.1

This immutable public-source release packages configuration-cache hardening
and behavior-preserving policy decomposition. It contains no production
configuration, credentials, database contents or website source.

## Upgrade notes

1. Verify the archive checksum, release manifest and GitHub attestation.
2. Treat `v1.10.79.1` as the previous immutable release and build both
   versions only from their verified public archives.
3. Rehearse upgrade, readiness, rollback, database restoration and forward
   recovery in disposable infrastructure before any operator adoption.
4. Run the explicit one-shot migration profile; this release adds no schema
   migration.
5. Provide replica and conformance signing material through the established
   runtime environment or secret-file entrypoint. The new provider keeps those
   runtime-only values outside Laravel's serialized configuration cache.

Registry and replica non-secret settings retain their existing environment
names and defaults. The extracted policies preserve registration, scoring,
pricing, discovery and public response behavior.

This release does not authorize deployment to the Genesis Seed or publication
of the unpublished IICP website.

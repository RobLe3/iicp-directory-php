# IICP PHP Directory v1.10.77

This is the first authoritative release produced from the standalone public
repository. It packages the public control-plane source only; it contains no
production configuration, credentials, database contents or website source.

## Upgrade notes

1. Verify the archive checksum and GitHub attestation.
2. Back up and restore the operator database into disposable infrastructure.
3. Apply migrations before starting the new application code. The event-chain
   head table is an expand-first migration and may safely remain after rollback.
4. Keep strict E050 and economic enforcement gates at their existing values.
5. Run health, OpenAPI contract and MariaDB concurrency checks before any
   separately authorized deployment.

See `CHANGELOG.md` and `RELEASE_POLICY.md` for details.

# IICP PHP Directory v1.10.87

This security patch updates Guzzle to 7.15.2, which rejects noncanonical URI
hosts and cookie domains covered by GHSA-v5mv-p594-2x33 and
GHSA-f7vp-7xgx-4w4r. IICP's endpoint validation and DNS-pinning boundaries
remain in place.

There is no database migration, OpenAPI change, wire change, ranking change or
Rust-directory release in this patch. Publishing does not by itself authorize
Genesis deployment.

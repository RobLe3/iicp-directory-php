# IICP PHP Directory v1.10.93

This candidate adds the disabled-by-default restricted trust-domain membership
foundation and the outcome-v2 reputation epoch. Heartbeat metrics are accepted
idempotently by batch identifier, and discovery exposes the score model and
epoch needed to interpret current scores.

The release also advances SDK release-currency evidence to 0.7.106. Public-mode
defaults remain unchanged. Preparing or publishing this release does not deploy
it to Genesis, enable restricted mode or authorize federation.

# IICP PHP Directory v1.10.82

This release adds a signed deployment-provenance record and aligns replica
credentials with the endpoint they protect.

## Changes

- `/.well-known/iicp-deployment.json` can bind a deployment to its release,
  source revision, artifact digest and protocol compatibility range.
- New replica JWTs use scope `GET /v1/snapshot`.
- The previous `GET /v1/events` scope remains accepted for one compatibility
  window so existing replicas can re-register without losing bootstrap access.
- The signed event tail remains public.
- A shared PHP/Rust fixture pins registration, rotation and snapshot-access
  behavior.

There is no schema migration or task-data-plane change. Publishing this release
does not authorize a Genesis deployment or a Rust cutover.

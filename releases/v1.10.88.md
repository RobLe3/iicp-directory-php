# IICP PHP Directory v1.10.88

This security patch updates Laravel to 13.24.0 and `league/commonmark` to 2.9.0,
which resolves the reviewed CommonMark denial-of-service and unsafe-link
advisories reported against 2.8.3.

There is no database migration, OpenAPI change, wire change, ranking change or
Rust-directory release in this patch. Publishing does not by itself authorize
Genesis deployment.

# IICP PHP Directory v1.10.90

This reliability release bounds the public 24-hour stats aggregate lookup by
selecting only the newest deterministic row per metric in SQL. It preserves the
existing response and cache contract while avoiding unbounded PHP hydration of
historical aggregate rows.

There is no database migration, OpenAPI change, route change, task-data-plane
change or cache-key change. Publishing does not by itself authorize Genesis
deployment.

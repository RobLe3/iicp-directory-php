# IICP PHP Directory v1.10.83

This release adds an authenticated and auditable replica decommissioning path.

## Changes

- `POST /api/v1/replicas/deregister` atomically decommissions the authenticated
  replica, expires and tombstones its bearer, and appends a signed
  `REPLICA_DEREGISTERED` event.
- Replica authentication now rejects expired, dormant, archived and
  decommissioned persistent rows independently of JWT validity.
- Re-registering the same DID preserves its `replica_id`, rotates its bearer,
  returns it to active state and resets trust to `low`.
- The versioned PHP/Rust lifecycle and HTTP fixtures pin the additive contract.

There is no schema migration or task-data-plane change. Publishing this release
alone does not authorize a Genesis deployment or a Rust cutover.

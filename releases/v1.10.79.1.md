# IICP PHP Directory v1.10.79.1

This release is the next immutable public-source candidate after the first
hardened operator baseline. It packages source only and contains no production
configuration, credentials, database contents or website source.

## Upgrade notes

1. Verify the archive checksum, manifest and GitHub attestation.
2. Treat `v1.10.78.1` as the previous hardened image and build both releases
   only from their verified public archives.
3. Back up and restore the operator database in disposable infrastructure.
4. Run the one-shot migration profile before starting `v1.10.79.1`; this
   release adds no schema migration.
5. Rehearse readiness, rollback to `v1.10.78.1`, database restoration and
   forward recovery before any separately authorized operator adoption.

The discovery optimization changes hydration mechanics only. It preserves the
selected columns, predicates, ordering, scoring and response contracts, and
adds no database index. The quality gates and classifier extraction have no
runtime configuration requirement.

This release does not authorize deployment to the Genesis Seed or publication
of the unpublished IICP website.

# IICP PHP Directory v1.10.89

This correctness release serializes reputation score, task-counter and hourly
positive-gain updates in one node-locked database transaction. Concurrent
heartbeats share the same persisted `+0.20` hourly budget, including after a
window reset or process restart.

There is no database migration, OpenAPI change, route change or task-data-plane
change. Publishing does not by itself authorize Genesis deployment.

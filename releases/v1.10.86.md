# IICP PHP Directory v1.10.86

This additive release separates a provider runtime's own name and version from
its SDK/wire compatibility version. It retains `sdk_version` as a migration
alias, rejects conflicting dual values, and moves readiness and adoption
calculations to the effective compatibility value.

The release advances the OpenAPI projection to 1.7.0 and includes a reversible
three-column node metadata migration. It does not change ranking, eligibility,
route exposure, the task data plane, strict E050 policy, or Rust's
operator-preview status. Publishing does not by itself authorize deployment.

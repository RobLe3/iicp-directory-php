# IICP PHP Directory v1.10.81.1

Security-alignment release for the current PHP Genesis implementation and the
Rust operator preview.

- TLS peer identity is verified during registration and lifecycle probes.
- Production federation requires signed events and a resolved seed key.
- Strict replicas do not apply unsigned snapshots or advance past rejected
  events.
- Development bypasses are explicit and cannot affect production.

This release contains no schema migration. Publication does not by itself
authorize a Genesis deployment; operators must complete the guarded deployment
and rollback gates separately.

# IICP PHP Directory v1.10.91

This additive release implements the shared effective-capability-v1 contract.
Registration, discovery, snapshots and replica replay preserve explicit
same-intent variants, version, lifecycle phase, bounded provenance and optional
extensions. Matching remains fail closed and never combines requirements across
variants.

The expand-first migration adds nullable capability version and phase columns.
Legacy capability fields and default discovery remain available. SDK release-currency
evidence advances to the coordinated 0.7.104 candidate. Strict E050,
ticketed-discovery defaults, federation and Genesis deployment do not change.
Publishing this release does not authorize production deployment.
